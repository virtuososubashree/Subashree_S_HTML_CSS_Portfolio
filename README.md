# Subashree_S_HTML_CSS_Portfolio
# Personal Portfolio Website

A responsive personal portfolio website built as part of the HTML & CSS Internship Project. This project serves to introduce my academic background, showcase my technical engineering skills, and display my latest projects.

## Live Demo
[View Live Site](https://virtuososubashree.github.io/Subashree_S_HTML_CSS_Portfolio)

## Technologies Used
* **HTML5**: Semantic document structure.
* **CSS3**: Custom styling, custom variables, Flexbox, CSS Grid, and responsive media queries.

## Features
* **Fully Responsive**: Adapts seamlessly to desktop, tablet, and mobile screens without horizontal scrolling.
* **Semantic Layout**: Uses standard HTML5 tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) for structure.
* **Modern CSS**: Utilizes Flexbox for navigation and skill chips, and CSS Grid for the project cards and contact layout.
* **Zero Dependencies**: Built entirely from scratch without JavaScript, Bootstrap, or any external CSS frameworks to meet internship core guidelines.

## Project Files
* `index.html` - The main structural document.
* `style.css` - The global stylesheet containing all design rules.
* `screenshots/` - Directory containing the required desktop and mobile view captures.
